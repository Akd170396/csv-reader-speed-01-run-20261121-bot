A fast drop-in replacement for csv-reader 1.0.0: it reads broken CSV files exactly the way csv-reader does — same columns, rows and error list on every input — in a single left-to-right pass with a per-record character scanner, indexOf jumps between quotes, and slice-based field extraction.

## Run it

```sh
node main.ts
```
